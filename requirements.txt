# The application requires the following free-tier credentials configured in backend/.env:
#
# 1. Groq Cloud AI API (Required for video/audio/quiz generation & AI Tutor):
#    - Provider: https://console.groq.com
#    - Variable: GROQ_API_KEY
#
# 2. Cloudinary (Required for storing user avatars and course document PDFs):
#    - Provider: https://cloudinary.com
#    - Variables: CLOUDINARY_CLOUD_NAME, CLOUDINARY_API_KEY, CLOUDINARY_API_SECRET
#
# 3. Gmail SMTP (Required for sending OTP verification emails):
#    - Provider: Google Account App Password (https://myaccount.google.com/apppasswords)
#    - Variables: EMAIL_USER, EMAIL_PASS
#
# 4. MongoDB Database:
#    - Variable: MONGO_URI (e.g. mongodb://localhost:27017/eduhub)
#
# 5. JWT Authentication:
